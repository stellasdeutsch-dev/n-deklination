# Слабые существительные в немецком — n-Deklination

Разбор слабого склонения существительных в сторителлинг-стиле: короткие фразы, диалоги без кавычек, сухие финалы.

**Сайт:** https://stellasdeutsch-dev.github.io/n-deklination/

## Что внутри
- Первый экран: падежи летают по орбите вокруг карточки der Student, форма меняется синхронно
- Цепочки предложений в стиле Дэна: слова печатаются, стрелки связывают повторы
- Конвейер склонения: сканер ищет приметы, штамп ставит Genitiv, слово падает в корзину (пауза и ×2)
- Машина окончаний с демо-режимом, трекер привычек и карточки интервальных повторений в цикле
- 3D-карусель экранов платформы, автопрокрутка видео, бегущие ленты отзывов с лайтбоксом
- 5 примет слабых существительных и ловушка (Politiker, Regisseur, Autor)
- Анимация по шагам: слабое против сильного, Nominativ → Plural
- «Машина окончаний»: слово + падеж → пошаговый выбор -n / -en
- Особые случаи: Herr, слова на -or, смешанное склонение (Name, Gedanke, das Herz)
- Шпаргалка, проверка по словарю, типичные ошибки
- Тренажёр на 12 слов и тест на 6 вопросов с разбором
- Витрина платформы Stellas A0–C1: видео, скриншоты, тарифы, отзывы

## Стек
Чистые HTML, CSS и JS, без сборки и зависимостей. Mobile-first, `prefers-reduced-motion` учтён.
